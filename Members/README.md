# 小木木會員資料庫（本機試作）

直接以瀏覽器開啟 `index.html`，即可搜尋，不需要安裝或啟動伺服器。

## 使用方式

- 搜尋帳號、名字、里 ID、表 ID、聯絡稱呼、信箱、備註或活動內容，會列出符合的會員。
- 左側有 HOME、朱紫、劍盾、ZA、阿爾宙斯、珍鑽、皮伊、GO 八大分類，可再篩選版本、國籍、身分、性別與跨遊戲帳號。
- 點開會員卡，查看該帳號的所有遊戲角色與相關活動。即使搜尋時選擇某個遊戲，詳細資料仍顯示所有遊戲。
- 已由使用者確認「菲蕾德翠卡」「海獺君」「木木」「ムム」「무무」「일월」皆為本人，整合為「木木（本人）」。原身分「胖丁」也歸入本人，身分改為「本人」，並在資料中保留 originalRole 供回查。原始帳號與 ID 不變，查詢原帳號仍可找到。
- 其他尚未填寫帳號的角色獨立保留；不以同名、里 ID 或表 ID 推斷同一個人。
- 可下載 Excel 填寫新增人員，回網頁匯入。此版本尚無修改既有資料、登入或跨裝置同步功能。

## 資料整理方式

來源為使用者提供的 `Poke訂單.xlsx`，保留每筆資料的工作表與 Excel 列號。

共用欄位：分類、里 ID、表 ID、名字、性別、版本、國籍、身分、帳號、備註、來源工作表、來源列。

HOME 額外欄位：方式、渠道、聯絡稱呼、日期、信箱。HOME 的 ID 視為角色名字，不當成數字表 ID。密碼完全排除，不會寫進 `data.js`。

- 帳號只去除頭尾空白與換行，並忽略英文字母大小寫來整合。不同拼字、不同平台帳號及暱稱尚未自動判定同一人。
- 本人歸屬為明確例外：名字正好為上述六個名字，或原身分為「胖丁」的既有與新增紀錄，均歸入「木木（本人）」。其他同名角色仍依原帳號整合。Excel 不以「本人」覆寫帳號；參考名單的原「胖丁」身分同步改為「本人」。
- 使用者已確認 Suisei 對應 Suisei Lin、幻亦玉對應 ortiz55；這兩個名字的空白帳號補入確認帳號，以 originalAccount 保留原空值，與既有帳號資料整合。若新資料已填不同帳號，不自動覆寫。
- 首頁「已歸屬會員」包含帳號整合與已確認的本人；「待確認歸屬」僅計算沒有帳號且未確認為本人的角色。目前本人有 32 筆、涵蓋 5 個遊戲分類；其餘待確認歸屬有 9 筆，先保留。
- 「皮伊&GO」依版本拆分。其他遊戲表中標示版本 GO 的列也歸到 GO，仍保留原工作表資訊。
- 「阿爾」分類統一改為「阿爾宙斯」，該分類的版本也固定為「阿爾宙斯」。舊 Excel 與瀏覽器儲存資料中的「阿爾」會自動轉換；原始工作表名稱保留供回查。
- 依使用者要求移除版本為太陽、白金、究極日、究極月、城都、豐原、關都、Y 的 10 筆角色紀錄；同帳號的其他版本保留。後續從原始工作簿更新或由網頁匯入，也會排除這些版本。
- 里 ID 與表 ID 使用文字，保留 Excel 的前導零及原有長度。未提供的欄位顯示「—」，不填入推測值。
- 排除標題及「虛擬帳號分隔線」，帳號單獨一列但缺少角色資訊的紀錄仍保留。
- 隱藏的「抽抽屋」「蛇年的阿柏怪」「龍年閃蛋」「IG追蹤領閃蛋」表作為補充活動。依原表帳號或 IG 帳號與會員關聯；找不到對應會員的活動也保留為獨立活動帳號，可從全部會員搜尋。
- 活動中的不同平台帳號尚未合併為同一個會員。已填帳號統計為目前整合後的帳號組數，包含活動帳號，不代表已確認的自然人人數。
- 「寶可夢練怪」為招式配置，未納入會員資料。
- 重複出現的原始角色或活動列保留，方便回查，不擅自刪除。

## 更新資料

### 自行填寫新增人員

1. 網頁點「下載 Excel 名單」，或開啟 `outputs/member-template/會員名單.xlsx`。
2. 到「新增人員」工作表，從第 2 列填寫；每列一個遊戲角色。黃色的分類、帳號、名字為必填，其餘可留白。里 ID、表 ID 已設為文字格式，保留前導零。
3. 同一人的不同遊戲角色分成多列，填寫同樣的帳號。分類、性別等有下拉選單可用。
4. 儲存 `.xlsx` 後，在網頁按「匯入 Excel」選取檔案。成功後立即可以搜尋，統計也會更新。

「現有名單」列出清理後的 587 筆角色供參考；「填寫說明」包含步驟與虛構範例，這兩張表不會匯入。

完全相同的資料列會略過，包括既有名單和重複匯入的新增人員；相同帳號但不同角色會保留。匯入採追加方式，變更已匯入列的內容會視為新紀錄，不會覆寫舊列。欄位錯誤時整份不匯入，畫面會指出列號；空白列與已移除的版本會略過。請維持欄名、不使用公式。

新增資料保存在目前瀏覽器的本機儲存空間，重新整理後仍可使用。不同裝置、瀏覽器、網頁網址或檔案位置可能使用不同的儲存空間，清除瀏覽器資料也會清除新增資料；請保留填寫過的 Excel，必要時重新匯入。網站不會上傳 Excel，也不會修改檔案中的原始資料。

Excel 匯入使用瀏覽器內建解壓縮功能，請使用近期版本的 Chrome 或 Edge。輸入檔僅接受一般 `.xlsx`，不支援加密檔、`.xls` 或 `.xlsm`。

### 從原始工作簿重建

先用 PowerShell 擷取工作簿至暫存區，再以 Node.js 更新本機資料：

```powershell
./Members/extract-workbook.ps1 -Path '你的 Excel 絕對路徑.xlsx' -Output "$env:TEMP/mumu-workbook.json"
node ./Members/prepare-data.mjs "$env:TEMP/mumu-workbook.json"
Remove-Item -LiteralPath "$env:TEMP/mumu-workbook.json"
```

擷取檔為短期處理資料，包含來源欄位，轉換後請刪除。原始 Excel 不會被修改。

本機試作尚未發布。`data.js` 包含實際會員資料，與頁面一起發布時，訪客可以取得該檔內容；正式多人使用前應改為有權限控管的資料儲存方式。
